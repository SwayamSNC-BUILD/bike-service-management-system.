
# BikeCare – Bike Service and Maintenance Management System

## About the Project
BikeCare is a web-based application developed to manage bike servicing and maintenance bookings. It helps users record customer details, bike information, service requests, booking status, and service costs.

## Features
- Dashboard for managing bike service bookings
- Add and manage customer bookings
- Store bike registration and service details
- Update booking status
- Track service costs and payments
- Manage service prices and offers
- Search and view booking records

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## Purpose
This project is developed as a college mini project for the Bachelor of Science in Computer Science program.
